ATUALIZAÇÃO — NAVEGAÇÃO POR MARCA E AGRUPAMENTO

1. Os carros são organizados por MARCA + NOME DO MODELO.
2. Motor, ano, versão e outras especificações não criam grupos separados.
3. Os resultados gerais ficam ordenados por marca e, dentro da marca, por modelo.
4. Navegar por marca pelos logotipos abre a página exclusiva da marca.
5. A página da marca mostra os modelos dessa marca por letras A, B, C...
6. O filtro "Marca e modelo" agora segue a mesma lógica:
   Marca → modelos daquela marca → modelo específico.
7. Escolher um modelo no filtro abre a página desse modelo com todos os carros do grupo.
8. "Ver todos os modelos" no filtro abre a página da marca.

Exemplos:
Toyota → Axio → todos os Toyota Axio
Toyota → Dyna → todos os Toyota Dyna
Mazda → Bongo → todos os Mazda Bongo
Mazda → CX-5 → todos os Mazda CX-5

Não foi necessário alterar o banco de dados/SQL para esta atualização.
