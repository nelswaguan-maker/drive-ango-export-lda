ATUALIZAÇÃO — AGRUPAMENTO DE MARCAS E MODELOS

1. Execute no Supabase o ficheiro: atualizacao-agrupamento-modelos.sql
2. Entre no painel de Administração.
3. Na secção "Agrupamento de marcas e modelos", clique "Agrupar agora".
4. O sistema mantém o nome original de cada anúncio e grava separadamente a marca/grupo do modelo.
5. O site usa esses grupos para apresentar: Marca → Modelo → carros daquele modelo.

Exemplo: 2009/3 TOYOTA HIACE VAN DX, TOYOTA HIACE VAN SUPER GL e Toyota hiace van DX ficam no grupo Toyota → Hiace Van.
