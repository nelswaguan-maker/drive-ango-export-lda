DRIVE ANGO — CONTACTOS GERAIS

O painel Admin agora tem dois grupos separados:
1. Contacto deste administrador: continua associado aos carros que esse administrador publica.
2. Contacto geral do Drive Ango: aparece no rodapé público.

Alterar o contacto geral NÃO altera publisher_phone/publisherPhone dos carros existentes.

Para ativar o armazenamento público, executar site-contact-settings.sql no Supabase (ou usar o bloco equivalente no supabase-schema.sql).
