DRIVE ANGO — V16 URLs bonitas

Os anúncios passam a usar URLs públicas no formato:
/car/marca-modelo-ano

Exemplo:
/car/toyota-hilux-z-2022

O Vercel encaminha /car/:slug para detalhes.html?slug=:slug. A página de detalhes resolve o slug usando os dados reais do catálogo. As URLs antigas /carro/:id continuam com compatibilidade.

Não foram alterados login, filtros, histórico, ANGO Assistant ou funções administrativas.
