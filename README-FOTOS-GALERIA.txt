
ATUALIZAÇÃO — FOTOS PELA GALERIA

O painel de administração agora permite escolher até 10 fotos diretamente da galeria do telefone/computador.
A primeira foto é a capa. As fotos são enviadas para o Supabase Storage no bucket "car-images".

Antes de publicar um carro com fotos pela primeira vez:
1. Abra o Supabase > SQL Editor.
2. Execute o conteúdo de storage-car-images.sql UMA vez.
3. Depois use o painel normalmente.

As outras configurações do projeto não foram alteradas.
