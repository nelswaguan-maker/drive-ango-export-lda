Política de Privacidade

DRIVE ANGO Export respeita a privacidade dos utilizadores. Esta página explica, de forma geral, como os dados fornecidos no site são usados.

Dados recolhidos

Podemos recolher nome, email, telefone e dados necessários para criar e gerir a conta. Também podemos receber informações técnicas básicas necessárias para autenticação e segurança.

Finalidade

Os dados são usados para criar contas, permitir autenticação, gerir favoritos e perfis, prestar atendimento e administrar o acesso autorizado ao painel.

Segurança

O acesso às contas é protegido por autenticação. O site não solicita palavras-passe através de WhatsApp.

Direitos

O utilizador pode atualizar os seus dados e solicitar a eliminação da própria conta através das funcionalidades disponibilizadas no site.

Contacto

Para dúvidas sobre privacidade, use os canais de contacto apresentados no site.
